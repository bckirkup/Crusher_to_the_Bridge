## 1. Scope, model contract, and statistical conventions

These tests cover the requested sections: pre-establishment clearance, cumulative exposure, established-infection clearance, shedding, clinical presentation, tissue tropism, timestep invariance, configuration validation, telemetry output, and migration. They are derived from the three supplied reports and the canonical code at the pinned snapshot.

The minimum state distinction assumed by the tests is:

- external delivered dose, $D_{p,j}$, by pathogen $p$ and portal/tissue $j$;
- retained viable pre-establishment inoculum, $R_{p,j}(t)$;
- cumulative establishment hazard, $H_{p,j}(t)$, or an exactly equivalent persistent-frailty implementation;
- established infection burden/state, $B_{p,j}(t)$;
- shedding, $S_{p,j}(t)$; and
- clinical state, $C_p(t)$, represented independently of shedding.

For a portal with no input during an interval, the reference pre-establishment update is

$$R(t+\Delta t)=R(t)e^{-\mu\Delta t}.$$

For a constant establishment rate coefficient $r$ over the interval, the exact accumulated establishment hazard is

$$\Delta H=\int_t^{t+\Delta t} rR(s)\,ds=
\begin{cases}
rR(t)(1-e^{-\mu\Delta t})/\mu,&\mu>0,\\
rR(t)\Delta t,&\mu=0.
\end{cases}$$

If the implementation instead treats an exposure dose as an instantaneous single-hit challenge, its conditional survival is $\exp(-rD)$ and repeated challenges must compose multiplicatively. The formal specification must select one interpretation and expose enough telemetry to test it; it must not mix a dose with a dose rate.

### Common statistical rules

1. Use deterministic unit tests wherever an analytic identity exists. Default floating-point tolerance is relative $10^{-10}$ and absolute $10^{-12}$ unless a row states otherwise.
2. For stochastic probability tests, use $N=100{,}000$ independent agents unless stated otherwise. Pass only if both (a) the analytic target lies in the two-sided Wilson 99% confidence interval and (b) absolute error is $\le 0.01$. This prevents a large sample from rejecting a scientifically negligible discrepancy while still enforcing a practical tolerance.
3. For time-to-event distributions, use $N=10{,}000$, a one-sample Kolmogorov–Smirnov (KS) test at $\alpha=0.01$, and the additional effect-size bound stated in the row. Censoring tests use Kaplan–Meier or Nelson–Aalen estimates with Greenwood confidence intervals.
4. For two stochastic simulator arms, use independent seeds unless a valid coupled-random-number implementation is explicitly being tested. Compare binary outcomes by a two-proportion test, continuous outcomes by bootstrap confidence intervals, and event-time distributions by a two-sample KS test. Timestep acceptance uses equivalence bounds, not merely “failure to reject.”
5. Fix and log the pseudorandom seed, code SHA, complete resolved configuration, clock mode, epoch duration, and replicate count. Run statistical tests at $\alpha=0.01$; within each section control the false-discovery rate at 1% by Benjamini–Hochberg. Deterministic invariants are not multiplicity-adjusted.
6. Test profiles use an exponential dose response when a closed form is needed and a beta-Poisson/persistent-frailty profile when heterogeneity is the subject of the test. Production profiles are tested separately as smoke/regression fixtures.

## 13. Release gates and execution tiers

### Pull-request gate

Run all deterministic tests; stochastic unit tests CEX-01/02, EIC-01/03, SHD-05, CLN-01/02/03, TRP-05 when enabled, and DTI-02/03 at their stated sample sizes; all schema tests; TEL-01 through TEL-06; and MIG-01 through MIG-08. No deterministic failure is waivable by statistical success.

### Nightly/full acceptance gate

Run every test, including all supported distribution families, all shipped pathogen profiles, 100-seed migration regression, complete timestep matrix, and performance guard. Save machine-readable per-test targets, estimates, confidence intervals, effect sizes, seeds, and resolved configs.

### Failure interpretation

- A failed analytic identity is a correctness failure, not a calibration issue.
- A confidence interval outside an equivalence margin is a timestep/migration failure even if a null-hypothesis test has $p>0.01$.
- A statistically significant but practically tiny difference inside the stated equivalence bound passes.
- A production profile that lacks an optional block may pass only through a documented fallback/default-off path; it must not silently acquire new behavior.
- Tests for unsupported optional features must be reported as **not applicable**, never silently skipped. The default-off equivalence tests remain mandatory.

## 14. Current-snapshot expectations

The current snapshot should already pass much of CEX-01/04/05/07/08, SHD-01/02/03/05/06, portions of DTI, existing CFG severity/observation rules, existing telemetry boundary tests, and the core migration seams. It is expected to fail or lack implementable interfaces for retained-inoculum decay (PEC), stochastic established-clearance distributions (EIC-01 through EIC-05), anatomical tissue tropism (TRP-02 through TRP-07), detailed new telemetry fields, and the recovery reset in MIG-06. Those are implementation gaps identified by the audit, not reasons to weaken the acceptance criteria.

## 15. Discretionary analytical decisions

- I treated “migration” as software/state migration from the current within-host implementation because the audit uses that term for backward-compatible integration constraints; shipboard embarkation/shore movement is outside this formal within-host scope.
- I made tests conditional on the declared clearance family rather than assuming all established clearance must be exponential. The current model is deterministic, while the literature review recommends configurable semi-Markov dwell times; an exponential-rate test is mandatory only when a rate model is selected.
- I used exact analytic comparisons for state updates and equivalence tests for stochastic timestep comparisons. A non-significant difference alone is not evidence of invariance.
- I set practical probability equivalence at 0.01, distributional KS effect bounds at 0.02–0.03, and moment tolerances at 2–5%. These are strict enough to detect meaningful numerical/model defects while avoiding failures caused only by Monte Carlo noise at the specified sample sizes.
- I preserved the repository’s current beta-frailty semantics in a dedicated test and added a separate model-family-consistency test because beta frailty and the classic approximate beta-Poisson formula are not analytically identical.
- I made tissue tests default-off plus conditional. The current repository has no anatomical compartments, so requiring tissue behavior unconditionally would break backward compatibility rather than test it.
- I treated clinical severity and shedding as orthogonal state dimensions. This follows both supplied literature reviews and the existing separate symptomatic/asymptomatic shedding curves.
