# Testing Dashboard (LCARS Command Deck)

## Prerequisites

- Python 3.11+ with `requirements.txt` installed (streamlit, plotly, pandas, numpy)
- Working directory: repo root (`Crusher_to_the_Bridge/`)
- Simulation telemetry generated by a prior orchestrator run

## Devin Secrets Needed

None.

## Quick Commands

### 1. Run dashboard unit tests (no Streamlit server required)
```bash
python -m pytest tests/test_dashboard.py -v --tb=short
```
Validates module imports, LCARS constants, `aggregate_transmission_pathway_totals()`, and `load_history()` when the file is missing.

### 2. Generate telemetry first
```bash
python orchestrator.py --epochs 24
```

### 3. Launch the dashboard interactively
```bash
streamlit run dashboard.py
```
Or use the launcher scripts:
```bash
./run_dashboard.sh
```

### 4. Verify pathway aggregation logic
```bash
python -c "
from dashboard import aggregate_transmission_pathway_totals
import json
with open('telemetry_buffer/simulation_history.json') as f:
    history = json.load(f)
totals = aggregate_transmission_pathway_totals(history)
print('Pathways:', sorted(totals.keys()))
"
```

## CI Coverage

GitHub Actions runs a lightweight dashboard import check after pytest (see `.github/workflows/ci.yml`). Full Streamlit rendering is validated manually or in review.

## Troubleshooting

- **Empty dashboard**: Run `python orchestrator.py` first to populate `telemetry_buffer/simulation_history.json`
- **Plotly import errors**: `pip install plotly streamlit pandas`
- **Wrong zone positions**: Verify `display` coordinates in `spatial_layout.json`
