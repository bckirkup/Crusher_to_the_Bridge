# Testing Dashboard (LCARS Command Deck)

## Prerequisites

- Python 3.11+ with `requirements.txt` installed (streamlit, plotly, pandas, numpy)
- Working directory: repo root
- Simulation telemetry generated by a prior orchestrator run

## Devin Secrets Needed

None.

## Package layout

| Module | Role |
|--------|------|
| `dashboard.py` | Streamlit entry script (`streamlit run dashboard.py`) |
| `dashboard/app.py` | Main command deck tabs and layout |
| `dashboard/theme.py` | LCARS colors, CSS, `apply_lcars_layout()` |
| `dashboard/charts.py` | Plotly charts, pathway aggregation |
| `dashboard/spatial_viz.py` | Tactical deck map with class photo plates |
| `dashboard/deck_geometry.py` | Hull silhouettes and compartment footprints |
| `dashboard/loaders.py` | Telemetry and notebook loaders |

## Quick Commands

### 1. Run dashboard unit tests (no Streamlit server required)
```bash
python3 -m pytest tests/test_dashboard.py -v --tb=short
```
Validates package imports, LCARS constants, `aggregate_transmission_pathway_totals()`, `apply_lcars_layout()`, and `load_history()` when the file is missing.

### 2. Generate telemetry first
```bash
python3 orchestrator.py --epochs 24
```

### 3. Precompute deck assets (optional, for class photo plates)
```bash
python3 scripts/precompute_deck_assets.py
# or one platform:
python3 scripts/precompute_deck_assets.py --platform enterprise_galaxy_tng
```

### 4. Launch the dashboard interactively
```bash
python3 -m streamlit run dashboard.py
```
Or use the launcher scripts:
```bash
./run_dashboard.sh
```

### 5. Verify pathway aggregation logic
```bash
python3 -c "
from dashboard import aggregate_transmission_pathway_totals
import json
with open('telemetry_buffer/simulation_history.json') as f:
    history = json.load(f)
totals = aggregate_transmission_pathway_totals(history)
print('Pathways:', sorted(totals.keys()))
"
```

## Dashboard Stations

| Tab | Purpose |
|-----|---------|
| Bridge Status Display | Ship status, biosensors, epidemic curves, infection counters |
| Tactical Sensor Grid | Class-accurate deck map with hull photo plates and contamination overlays |
| Sickbay Diagnostic Console | Lab notebook at LOW/MID/HIGH fidelity |
| Standing Orders & Threat Profiles | SOP cards with `exempt_classes`, pathogen dossiers |
| Fleet Operations | Presidio cruise comparison when fleet telemetry is available |

## Telemetry Fields the Dashboard Expects

| Field | Used For |
|-------|----------|
| `summary.quarantined` | Confined to Quarters count |
| `summary.isolated` | Isolation Ward count |
| `summary.quarantine_refusers` | FRED non-compliance |
| `infection_counters` | Attack-rate time series, threshold indicators |
| `wearable_monitoring` | Fever/anomaly rates |
| `contact_tracing.transmission_events[].pathway_breakdown` | Transmission vector pie chart |
| `agents[].agent_class` | Crew Manifest by Division table |
| `agents[].infection_state`, `symptom_presentation`, `compliance_status` | Orthogonal agent axes |

## CI Coverage

GitHub Actions runs a lightweight dashboard import check after pytest (see `.github/workflows/ci.yml`): package import, pathway aggregation, and `apply_lcars_layout()` Plotly styling. Full Streamlit rendering is validated manually or in review.

## Troubleshooting

- **Empty dashboard**: Run `python3 orchestrator.py` first to populate `telemetry_buffer/simulation_history.json`
- **Missing deck photo plate**: Run `python3 scripts/precompute_deck_assets.py` for the active platform
- **Plotly import errors**: `pip install plotly streamlit pandas`
- **Wrong zone positions**: Verify `display` coordinates in `spatial_layout.json`
